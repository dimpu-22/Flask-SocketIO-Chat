# 💬 Flask SocketIO Chat Application

A Real-Time Chat Application developed using **Flask**, **Flask-SocketIO**, **SQLite**, **HTML**, **CSS**, and **JavaScript**. The application enables users to communicate instantly through real-time messaging with a modern and responsive interface.

---

## 🚀 Features

- 👤 User Registration & Login
- 💬 Real-Time Messaging with Flask-SocketIO
- 📜 Chat History (SQLite Database)
- 🟢 Online Users Counter
- ⌨️ Typing Indicator
- 📢 Join & Leave Notifications
- 🕒 Message Timestamps
- 🔄 Auto Scroll to Latest Message
- 🚪 Logout Functionality
- 📱 Responsive User Interface

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Flask, Flask-SocketIO
- **Database:** SQLite
- **Language:** Python

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/dimpu-22/Flask-SocketIO-Chat.git
```

### 2. Navigate to the Project Folder

```bash
cd Flask-SocketIO-Chat
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open Your Browser

```
http://127.0.0.1:5000
```
